📚 Glossary of Computer Terms

CPU - Central Processing Unit
The brain of the computer that executes instructions from programs. It performs calculations and manages data flow between components.
GPU - Graphics Processing Unit
A specialized processor designed to accelerate graphics rendering, video editing, and AI workloads. GPUs have thousands of cores for parallel processing.
RAM - Random Access Memory
Temporary, fast memory that stores data the CPU needs to access quickly. RAM is volatile and loses data when the computer is turned off.
VRAM - Video RAM
Specialized memory on the GPU used to store textures, frame buffers, and other graphics data. Higher VRAM allows for better gaming and creative performance.
SSD - Solid State Drive
A storage drive that uses flash memory to store data. SSDs are much faster than HDDs, with no moving parts, making them more reliable and quieter.
HDD - Hard Disk Drive
A storage drive that uses spinning magnetic platters to store data. HDDs are slower than SSDs but offer more storage capacity for the price.
NVMe - Non-Volatile Memory Express
A storage protocol designed for SSDs that uses the PCIe interface. NVMe drives are significantly faster than SATA SSDs, with speeds up to 10,000+ MB/s.
PCIe - Peripheral Component Interconnect Express
A high-speed interface used to connect components like GPUs, NVMe drives, and network cards. PCIe uses lanes for data transfer, with more lanes offering higher bandwidth.
SATA - Serial ATA
A storage interface used to connect HDDs and SSDs to the motherboard. SATA III has a maximum speed of 6 Gbps (about 600 MB/s).
PSU - Power Supply Unit
The component that converts AC power from the wall into DC power for computer components. PSU quality and wattage are critical for system stability.
TDP - Thermal Design Power
The maximum amount of heat a component generates under typical workload. TDP is measured in watts and helps determine cooling requirements.
GHz - Gigahertz
A unit of frequency equal to one billion hertz. CPU clock speeds are measured in GHz, indicating how many billion operations per second the CPU can perform.
Core
An individual processing unit within a CPU. Multiple cores allow the CPU to perform multiple tasks simultaneously.
Thread
A sequence of instructions that can be executed independently. Threads allow each CPU core to handle multiple tasks at once (simultaneous multithreading).
Cache
Ultra-fast memory built into the CPU for quick data access. Cache stores frequently used instructions and data to improve performance.
Chipset
A set of chips on the motherboard that controls data flow between the CPU, RAM, storage, and peripherals. The chipset determines what features the motherboard supports.
Socket
The physical connector on the motherboard where the CPU is installed. Different CPU generations use different socket types.
BIOS - Basic Input/Output System
Firmware that initializes hardware during boot and provides runtime services for the operating system. The BIOS is stored on a chip on the motherboard.
UEFI - Unified Extensible Firmware Interface
The modern replacement for BIOS. UEFI offers faster boot times, better security, and a graphical interface for configuring system settings.
FPS - Frames Per Second
The number of frames displayed per second in a game or video. Higher FPS results in smoother and more responsive gameplay.
Refresh Rate
The number of times a display updates its image per second, measured in Hertz (Hz). Higher refresh rates (e.g., 144Hz, 240Hz) provide smoother motion in games.
