🧠 RAM - Random Access Memory

RAM is your computer's short-term memory. It temporarily stores data that your CPU needs to access quickly. Unlike storage (SSD/HDD), RAM is volatile - it loses all data when the computer is turned off. More RAM allows your computer to handle more applications simultaneously and work with larger files.

Capacity determines how much data can be stored. Speed (measured in MHz) affects how quickly data can be accessed. Dual-channel memory uses two RAM modules together for better performance. Laptop RAM (SO-DIMM) is smaller than desktop RAM (DIMM).

DDR3 RAM

Purpose: Older systems, budget upgrades

DDR3 is an older generation of RAM that's still found in many older computers. While slower and less power-efficient than newer generations, it's affordable and suitable for basic computing on older systems.

DDR4 RAM

Purpose: Current mainstream systems

DDR4 is the current mainstream RAM standard for most computers. It offers higher speeds, lower voltage, and greater capacity than DDR3. DDR4 is found in nearly all modern desktop and laptop computers.

SO-DIMM / Laptop RAM

Purpose: Laptops and small form factor systems

SO-DIMM (Small Outline Dual Inline Memory Module) is the smaller RAM format used in laptops, mini PCs, and some small form factor desktops. It's physically shorter than desktop RAM but offers similar performance.
