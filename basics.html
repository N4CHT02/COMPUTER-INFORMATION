📖 Computer Basics

What is a Computer?

A computer is an electronic device that processes data, performing calculations and operations according to instructions provided by software. Computers can store, retrieve, and process information to help users accomplish tasks.

Hardware vs Software

Hardware is the physical parts of a computer that you can touch — the monitor, keyboard, CPU, RAM, storage, and more. Software is the set of instructions (programs) that tell the hardware what to do. Both are necessary for a computer to function.

Input Devices

Input devices send data to the computer. They include the keyboard, mouse, touchpad, touchscreen, microphone, camera, and scanner. These devices allow you to interact with and control the computer.

Output Devices

Output devices display or present information from the computer. They include monitors, speakers, headphones, and printers. These devices show you the results of the computer's processing.

Key Components

CPU: The brain that processes instructions.
RAM: Temporary memory for active tasks.
Storage: Permanent memory for files and software.
GPU: Handles graphics and visual processing.
Motherboard: The circuit board connecting all components.
PSU: Supplies power to all components.
Operating System: Software that manages hardware and software resources (Windows, macOS, Linux).
